    Roadmap to the platinum — seven stages, in order

    Built from the official descriptions: story chapters and named missions first (with a manual save before each), the stranger strands while their links unlock, then collectibles, activity mastery, the crime-and-money stage, and a cleanup for 100% and the cryptic one-offs. Missable-watch trophies are flagged wherever they appear — grab those moments when the story offers them, not in cleanup.

    Missable watch — five trophies to protect

    No trophy on the official list is labelled missable by PlayStation. These five are flagged because their official descriptions describe a single moment, a scripted set piece, or a finite counter — the wording itself is the warning. The defence is cheap and universal: keep a manual save before every story mission, take the moment when it appears, and never overwrite your pre-finale save.

    Sources & method

    How this guide was built

    Every trophy name, description and grade is reproduced exactly as PlayStation publishes them, cross-checked between the Exophase and PSNProfiles listings of the official PS5 list (55 trophies: 1 platinum, 2 gold, 6 silver, 46 bronze). Each trophy's requirement, count and roadmap stage are derived from its official description; where a description is cryptic, the guide says so and gives the safest reading instead of inventing detail. All strategy text is original to this guide — sources are cited beside each trophy, never copied. Kinds: story and named missions, collectibles and exploration, activities and grinds, plus the platinum. The official list contains no online trophies. The artwork is this page's own CSS sunset — no game artwork or logos are used.

    Tracker notes

    Your checklist is stored only in this browser (localStorage, key leonida-legend-progress-v1). Export downloads a small JSON file of your earned trophies; import reads that same file back on any device. The spoiler shield hides the names and descriptions of unearned story trophies — tick one as earned to reveal it. Filters combine: kind, grade, status and search all apply at once, and the address bar hash (for example #view=roadmap or #grade=silver) records the current view so it can be bookmarked.
